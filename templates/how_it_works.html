How unusual days are detected

{% if is_public %} Full transparency into the algorithm — no black boxes. This page uses sample data so anyone can see exactly how a day gets flagged. {% else %} Full transparency into the algorithm behind {{ person_name }}'s alerts. No black boxes. {% endif %}

In plain words

The system does not use fixed thresholds like "alert if activity drops below 50". Instead, it learns what is normal for this specific person by looking at their recent history, then measures how far today is from that personal baseline. A day is flagged only if the deviation is statistically significant across one or more metrics.

The algorithm, step by step

  1. Build a baseline. For every day being evaluated, take the previous 7 days of that person's data as their current "normal".
  2. Compute deviation per metric. For each metric — activity level, sleep hours, wake-ups, meals — compute how many standard deviations today's value is from the mean of the 7-day window. This is called a z-score.
  3. Apply a floor to the spread. If the 7-day window happened to be unusually steady, a tiny change could look huge in z-score terms. A per-metric floor prevents this — the standard deviation is never allowed below that floor.
  4. Flag if either condition is met. A day is marked unusual if (a) any single metric has a z-score at or above its severe threshold, or (b) the weighted sum of all z-scores crosses the combined threshold of {{ combined_threshold }}.

Why this design

  • Adaptive, not fixed. Fixed thresholds cause alert fatigue — a naturally calm person triggers constant false alarms. Per-person baselines avoid that.
  • Per-metric floors. Without them, an unusually steady week would make tiny changes look statistically extreme, and false positives would spike.
  • Multi-signal. A single "unusual" metric is often noise. Two or three shifting together is a stronger signal — which is why the combined score exists.
  • Transparent. This page exists because we think families deserve to know why an alert was raised — not just be told that it was.
