Frequently asked

Honest answers to reasonable questions

Do I need a wearable or special hardware?+
No. You can log activity manually, and the system also exposes a device-authenticated API endpoint — the same kind of interface a real wearable or home sensor would use.
How does it know what "normal" looks like?+
The system learns each person's own baseline from their recent activity history, then flags days that deviate meaningfully from that baseline. See the exact math →
What happens during the first week?+
The dashboard honestly shows "building baseline" for the first 7 days, since there isn't yet enough history to judge what is normal for that person.
Can more than one family member use it?+
Yes. Multiple family accounts can be linked to the same elderly person, and a single family account can monitor multiple relatives.
Is my data secure?+
This is a college project, so authentication is intentionally simplified — enough to demonstrate the flow, not enough for production.
