How it works

  1. Your phone reads its accelerometer via the browser's DeviceMotion API.
  2. Every 3 seconds, motion energy is summarized into a single reading (roughly 80–120 for gentle movement).
  3. That reading is POSTed to /api/sensor-data with the API key — the same endpoint a real wearable would use.
  4. The server records it against the linked elderly person using the same "one entry per person per date" rule.

Note on iOS: Safari requires HTTPS for motion sensors. If you're on iPhone, this page won't work over plain HTTP. Android Chrome works fine over your local network.
